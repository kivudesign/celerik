# Getting started

Celerik UI is a set of PHP components (Grid, Chart, Form, Scheduler, Modal, Tabs, Notification, File Manager and ThemeBuilder) that render Bootstrap 5 markup. A small JavaScript bundle then enhances them with open-source libraries such as DataTables, Chart.js and FullCalendar, each loaded only on the pages that use it.

## Requirements

- PHP 8.2 or later
- Bootstrap 5.3 and jQuery 3.7 on the page (peer dependencies)
